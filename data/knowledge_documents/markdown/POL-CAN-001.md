## Cancellation before dispatch

Customers may request cancellation while an order remains in Processing and warehouse dispatch has not begun. Cancellation is complete only when the order status confirms Cancelled. Submitting a request or opening a support ticket is not itself confirmation that the order has been cancelled.

Once an order is marked Shipped, standard self-service cancellation is unavailable. The customer may review the applicable return process after delivery. Some orders may become non-cancellable earlier if fulfillment has already begun, even if a carrier tracking number has not yet received its first scan.

The assistant may explain the cancellation policy and retrieve order status through an authorized backend tool. It must not claim that an order was cancelled unless the backend confirms the resulting status. Refund timing for a successfully cancelled order depends on the payment state and the payment provider.
